# Лабораторна робота №3

## Варіант

Номер залікової книжки: 4110

V = 4110 mod 3 = 0

Варіант 0: Електронна комерція та стрім транзакцій.

## Опис

Проєкт реалізує сервіс аналітики `TransactionStreamAnalyzer` для безпечної фільтрації
та трансформації нескінченних потоків даних `Stream<Transaction>`.

Методи:
1. `findFirstHighValueTransaction()` - знаходить першу транзакцію, що перевищує заданий ліміт. Повертає `Optional`.
2. `takeTransactionsUntilBudgetExceeded()` - вибирає транзакції зі стріму, поки їхня сума не перевищує ліміт бюджету.
3. `processBatches()` - розбиває нескінченний стрім на фіксовані вікна.
